# Etemad — Verified Afghan Marketplace

Interactive classroom prototype for the American University of Afghanistan MGT 352 Senior Project.

## Open the demo
This standalone `index.html` requires no build step. Repository: https://github.com/HamidSharafuddin/etemad-marketplace.

## Features
- Responsive desktop and mobile interface
- English, Dari and Pashto language selector (navigation and introduction translated; some workflow text remains English)
- Searchable cosmetics and textiles marketplace with fictional Afghan sellers
- Free, Silver and Gold annual membership pricing
- Gold-only bidding with 3% commission on completed auctions
- Seller registration, admin verification and dispute review
- Demo ratings and direct-contact messages
- Year 3+ illustrative checkout/escrow with commission calculations
- Five-year business-plan roadmap

## Limitations
All businesses, documents, bids, ratings, messages and transactions are fictional. Changes are saved only in the browser's localStorage. No actual authentication, payment, escrow, document checks or messaging services are connected. Educational demonstration only.

## Publish using GitHub Pages
Open repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. Expected URL: https://hamidsharafuddin.github.io/etemad-marketplace/

## Classroom walkthrough
1. Filter marketplace products.
2. Contact a seller and rate a listing.
3. Place a Gold auction bid and close a simulated sale.
4. Submit a seller application and approve it in Administration.
5. Switch to Year 3 and demonstrate simulated checkout.
6. Explain the five-year roadmap.

Based on the October 2026 Etemad business plan.
